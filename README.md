# Hi, I'm Harsh Deshpande 👋

## [![Typing SVG](https://readme-typing-svg.demolab.com?font=Google+Sans&duration=4000&pause=500&color=6F00FF&width=435&lines=Senior+Software+Engineer;WSAudiology+%7C%F0%9F%A6%BB;%F0%9F%93%8D+Hyderabad%2C+India)](https://git.io/typing-svg)

Full-stack engineer with *5+ years* in the *.NET* and *React* ecosystems. At [![](https://img.shields.io/badge/WSAudiology-8A2BE2)](https://www.wsa.com/), I build cloud-native, event-driven platforms for hearing care: *C# / .NET* microservices on the backend, *React + TypeScript* on the frontend, shipped through *Kubernetes, GitOps, and Infrastructure-as-Code* on *Azure*.

I enjoy scalable, high-performance architecture, clean object-oriented design, and the kind of test automation that lets regulated medical-device software move fast without breaking things.

---

## 🧭 What I do

- Design and build *microservices around Domain-Driven Design*: bounded contexts, aggregate roots, and domain events
- Orchestrate long-running workflows with *sagas* and *message consumers* over an *event bus*
- Build rich, real-time *React SPAs* with server-state caching, live updates over *SignalR*, and offline-tolerant telemetry
- Automate quality end-to-end: unit, contract, *BDD, UI, and desktop E2E* tests across multiple regions and environments
- Collaborate with *global engineering teams* and use *AI-assisted engineering* daily — GitHub Copilot agents, *MCP* servers, and agent skills
